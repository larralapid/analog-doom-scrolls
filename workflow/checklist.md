# Haul checklist

Copy this checklist into the working notes for each new haul. Check each item when you have verified it.

## Capture

- [ ] Photograph the entire stack straight on in diffuse light. All spines and edges are in frame.
- [ ] Check the photos at full size for glare and motion blur. Retake any frames where lettering is hard to read.
- [ ] Photograph one interior page from each book for the carousel. Save the full-stack photo and the page photos under `NNN/photos/`. Name pages by top-to-bottom book order, for example `01-page.jpg`, and link each interior page in the corresponding Books row under `page_photo` in `post.md`.
- [ ] Use a cover, title-page photo, or checkout record to identify books with worn or hidden spine lettering.

## Before rendering

- [ ] Count the books and transcribe title, author, and edition when relevant. Add ISBNs when available.
- [ ] Compare against the README and prior haul records, including unpublished drafts. Check title variants, punctuation, subtitles, author names, and ISBNs. If a book already appears or may be a match, give Larra the title, prior haul number, and why it matched. Wait for her decision before generating the video. Record any approved repeats.
- [ ] Retouch the photo in Photoshop or an equivalent editor. Crop, remove the room background and cast shadows, and reduce glare while preserving the spine artwork, lettering, labels, and proportions.
- [ ] Validate every spine against the source photo and verify the book count and top-to-bottom order.

## Export and archive

- [ ] Check the first frame, the typing sequence, book arrivals, both stamps, the final hold, and the full checkout card through the bottom margin.
- [ ] Add and tailor the sound. Verify the typewriter clicks, one thump per book, and both stamp strikes against the encoded video. Listen through both audio channels.
- [ ] Preview the export on a phone with the TikTok caption safe area covered. Verify titles, book edges, and stamps clear the caption.
- [ ] Store the final MP4, selected photos, and `post.md` under the haul number. Record the actual GitHub video URL and update the README index.
- [ ] If the production prompt changed, commit the revised prompt to GitHub with the haul.

## Publish

- [ ] Copy the plain-text block directly below the first heading in `post.md` into TikTok and verify the post uses the project account.
- [ ] After the post is live, set `status: published`, fill in the actual `publish_date` and `publish_url`, and regenerate the README index.
