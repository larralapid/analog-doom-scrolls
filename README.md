## Make a haul

<details>
<summary><samp>Capture → check for repeats → render → publish</samp></summary>

1. Photograph the stack and one interior page per book. Record titles and authors in spine order in the **Books** table in the next numbered folder’s `post.md`.
2. Check every prior haul, including drafts. If a book might be a repeat, flag it to Larra and wait for her decision before rendering.
3. Follow the production prompt and checklist. Archive the final MP4 and photos, set the video URL in the post properties and place image links in the Photos section.
4. Run `python3 scripts/update_book_index.py` with PyYAML installed. It builds the caption and running total from the Books table. Add interior-page image links in its `page_photo` column. Copy the text block under the haul heading into TikTok.
5. Once live, set the post’s status to `published`, enter its date and URL, and regenerate. Commit the haul, index, and any approved prompt revisions together. Use `--check` to verify the generated files.

</details>
