## Make a haul

1. Photograph the full stack, then one interior page per book. Use the next available three-digit haul number or the existing number when revising a haul.
2. Identify the books and check this index and the per-haul records for repeats **before rendering**. Flag any matches to Larra and wait for her decision. Confirm obscured spine text using another photo, the title page, the checkout list, or the library catalog.
3. Follow the production prompt and checklist. Archive the final MP4 and carousel photos in the haul folder. Copy the caption template to `NNN/caption.md` and record the books in top-to-bottom order.
4. After publishing, record the TikTok post URL and actual date in that caption file. Regenerate the index in the same commit. The haul number below then links directly to the TikTok post.
5. Commit prompt revisions here as they are approved. Resume from the latest GitHub version in a new chat.

The `caption.md` files hold the publication metadata and book list. To refresh the section below, run `python3 scripts/update_book_index.py` with PyYAML installed. Run the same command with `--check` to verify the generated section.
